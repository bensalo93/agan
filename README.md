# לומדות רצפת אגן

אתר לימוד אישי לקורס שיקום רצפת אגן. אתר סטטי, בלי שלב בנייה, מתאים ל-GitHub Pages.

- `content/course.js` – רשימת השיעורים
- `content/lesson-XX.js` – תוכן שיעור: יחידות, תרגול, כרטיסיות ומקורות. הפניה בטקסט נכתבת כך: `{{ID|מיקום}}`
- `assets/diagrams.js` – תרשימים סכמטיים
- `assets/app.js` – המנוע (ניתוב, תרגול, כרטיסיות, התקדמות ב-localStorage)

כדי להוסיף שיעור: יוצרים קובץ `content/lesson-02.js` באותו מבנה, ומוסיפים תגית script ב-`index.html`.
